# Visualizador de Músculos

Una aplicación web simple construida con Vite y React que permite visualizar un SVG del cuerpo humano y colorear diferentes grupos musculares.

## Características

- 🎨 Visualización interactiva del cuerpo humano con músculos
- 🖌️ Colorear músculos individuales haciendo clic en ellos
- 🎨 Paleta de colores predefinida y selector de color personalizado
- 📱 Diseño responsive y moderno
- 🔄 Función para limpiar todos los colores

## Instalación

1. Instala las dependencias:
```bash
npm install
```

## Uso

1. Inicia el servidor de desarrollo:
```bash
npm run dev
```

2. Abre tu navegador en la URL que aparece en la terminal (generalmente `http://localhost:5173`)

3. Para colorear un músculo:
   - Selecciona un color de la paleta o usa el selector personalizado
   - Haz clic en el músculo que deseas colorear en el SVG
   - Vuelve a hacer clic para quitar el color

4. Usa el botón "Limpiar Colores" para resetear todos los músculos

## Músculos incluidos

- Pectorales
- Deltoides
- Bíceps
- Tríceps
- Abdominales
- Oblicuos
- Cuádriceps
- Gemelos
- Glúteos
- Dorsales
- Trapecio

## Scripts disponibles

- `npm run dev` - Inicia el servidor de desarrollo
- `npm run build` - Construye la aplicación para producción
- `npm run preview` - Previsualiza la build de producción

## Tecnologías

- React 18

- CSS3
